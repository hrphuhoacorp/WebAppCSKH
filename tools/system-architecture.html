1. Tổng quan hệ thống

WebAppCSKH là hệ thống quản trị nội bộ đa module dành cho doanh nghiệp bán lẻ giỏ quà PhuHoa Fresh, được xây dựng theo mô hình SPA (Single Page Application) với backend RESTful API.

🛎️ Chăm sóc khách hàng (CSKH)

Quản lý đơn hàng, khách hàng, import Excel từ Sapo, dashboard doanh thu, phân tích tỉ lệ quay lại.

🎁 Giỏ quà

Quản lý kho ảnh, mã đổi giỏ quà, yêu cầu đổi mã, duyệt mã, tích hợp Sapo Sales.

📦 VPP (Văn phòng phẩm)

Quản lý danh mục, nhập kho, xuất kho, kiểm kho, tồn kho, phiếu đề nghị cấp phát.

👥 Nhân sự

Danh sách nhân viên, import, sinh nhật, lịch sử thao tác, phân quyền theo role.

🧑‍💼 Tuyển dụng

Campaign tuyển dụng, quản lý ứng viên, gửi email tự động, cấu hình template mail.

📰 Nội bộ

Tin tức nội bộ, thông báo, ghim bài, quản lý media (upload ảnh/video).

📊 Bán hàng & Sapo

Import dữ liệu Sapo, kiểm NXT giỏ quà, phân tích doanh thu, tỉ lệ quay lại.

🔐 Phân quyền

RBAC + user-level permissions, 53 permission codes, JWT cookie-based auth.

🔧 Tiện ích

Kiểm tra mã hàng Sapo (standalone HTML), đề nghị cấp phát VPP, tổng hợp link.

10. Quy ước & Conventions

Backend

Chủ đềQuy ước
DateTimecreated_at, updated_at: DB tự set (không gán trong code). deleted_at: DateTime.UtcNow.AddHours(7)
Ngoại lệ VPPGán CreatedAt = DateTime.UtcNow trực tiếp trong service
Soft deleteCheck DeletedAt == null trong query, không xóa vật lý
Error handlingThrow NotFoundException, ConflictException, BadRequestException — global middleware bắt và trả status code phù hợp
JSONCamelcase naming, Enum as string, DateTime UTC converter
PatternRepository + UnitOfWork, DI scoped, không có logic trong controller
MigrationTạo cả .cs và .Designer.cs, cập nhật MemBerContextModelSnapshot. Tắt backend trước khi chạy migration (DLL bị lock)
