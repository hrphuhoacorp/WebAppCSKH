# Project Rules

## Backend

- ASP.NET Core 9
- Clean Architecture
- CQRS
- MediatR
- Repository Pattern
- PostgreSQL
- EF Core

## Frontend

- React
- Vite
- TypeScript
- MUI
- Redux Toolkit
- RTK Query

## Coding Style

- Không dùng var nếu có thể suy luận rõ.
- Không viết code trùng.
- Ưu tiên async/await.
- Không thêm package mới nếu chưa cần.

## Database

Không được xóa migration cũ.

Migration mới đặt tên rõ ràng.

## Before finishing

Always

- dotnet build
- npm run build

Fix all compile errors before asking user.
